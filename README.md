# 神楽坂/飯田橋グルメ 一覧マップ

**https://gourmetmap.github.io/kagurabashi/**

Instagram [@kagurabashi_gourmet](https://www.instagram.com/kagurabashi_gourmet/) が神楽坂・飯田橋周辺で実際に食べたお店を、料理の味だけで★1〜★5の5段階で評価し、地図にまとめたサイトです。ラーメン、和食、居酒屋、焼き鳥、焼肉、中華、アジア・エスニック、カレー、イタリアン、フレンチ、洋食、バーなど、ジャンルや星の数で絞り込めます。

## 星の基準(料理の味のみ。接客・雰囲気・値段・ドリンクは考慮外)

| 星 | 基準 |
|---|---|
| ★★★★★ | 死ぬほど美味しい |
| ★★★★ | めっちゃ美味しい |
| ★★★ | かなり美味しい(リピートしたい) |
| ★★ | 普通に美味しい |
| ★ | 好みではない |
| ★対象外 | ドリンク中心のお店 |

## ファイル

- `index.html` / `app.js` — 地図ページ
- `data.csv` — 掲載店のデータ(店名・ジャンル・星・予算・コメント・住所・座標)
- `llms.txt` — 全店の評価をテキストでまとめたもの
- `img/` — 各投稿の1枚目の写真

地図: [国土地理院](https://maps.gsi.go.jp/development/ichiran.html) / [Leaflet](https://leafletjs.com/)
